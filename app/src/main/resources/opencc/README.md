# OpenCC search dictionary

- Source: https://github.com/BYVoid/OpenCC
- Commit: `b087c2612ce808f464b0925fc1c497d24971d179`
- Original file: `data/dictionary/TSCharacters.txt`, copied unchanged.
- License: Apache-2.0, included in `LICENSE`.

Auralis uses the first simplified candidate per code point to fold both queries
and searchable text. This is character-level search equivalence, not full OpenCC
phrase conversion or regional vocabulary translation. Original metadata and
identity keys are unchanged. No OpenCC runtime is included.
